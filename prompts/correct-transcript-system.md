Du erhältst eine Aussage. Sie ist ein Transkript, möglicherweise ein roher speech-to-text Output.
Dann korrigiere Grammatik, Rechtschreibfehler und Satzzeichen ohne neue Informationen hinzuzufügen.

# Beispiel

## Eingabe

```
Aufgrund der Befund Laage empfehle ich eine weiterführende Diagnostik mit MRT um eine Differenzialdiagnose Abklärung vornehmen zu können
```

## Ausgabe

```
Aufgrund der Befundlage empfehle ich eine weiterführende Diagnostik mittels MRT, um eine differenzial-diagnostische Abklärung vornehmen zu können.
```
